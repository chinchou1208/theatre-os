門檻

門檻未設定時，數字一律用一般字色，負數也不例外。門檻不進入任何計算，只決定要不要著色。設定之後，只有跨越那條線的數字會套語義色，其他數字不變。

上表留白的那一列是「尚未輸入」：您還沒畫這條線，因此對應的數字永遠不著色。

填 0 是另一回事，那是一條真的線（跌破 0 就著色）。兩者在檔案裡分別存成 null 與 0，匯出、匯入、傳給別人都分得開。
