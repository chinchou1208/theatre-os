# Theatre OS（測試版）

劇場製作的決策工具：商業計算器（拍板前模擬）＋排程反推器（死線倒推）。
完全在瀏覽器內運作——無帳號、不上傳、資料不離開你的電腦。

**直接使用**：https://chinchou1208.github.io/theatre-os/

## 這一版有什麼

- 六個分頁：總覽、製作、商業、排程、報表、設定
- 總覽的決策問答列：用製作人會說的句子提問，每一條都能展開看推導（輸入值／公式／換算／假設）
- 排程反推器：從死線倒推每件事最晚何時啟動，紅黃綠燈；工期未估就顯示「未估」，不以 0 代入
- 匯出 Excel：三張人看得懂的表（收支預算、場次與場租、票圖），丟回工具可完整還原
- 骨架匯出：數字清空、只留結構，可以把表的骨架傳給同行

## 測試版注意

⚠️ **資料目前存在瀏覽器裡，清除瀏覽資料會遺失專案。** 重要內容請用「匯出專案」存成檔案。
（檔案自動儲存機制開發中——之後會改成像 Word 一樣直接存回你選的檔案。）

## 關於數字

工具只呈現事實與計算，不替你做決定。沒有填的欄位一律顯示「尚未輸入」或「未估」，不會用 0 或預設值假裝有答案；任何推估都會標明是你填的假設，不是工具的斷言。
